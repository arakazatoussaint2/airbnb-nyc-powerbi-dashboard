# Airbnb NYC Dashboard (Power BI)

## Project Overview
This project presents an interactive Power BI dashboard analyzing the Airbnb market in New York City. It provides insights into listings distribution, pricing, popularity, and host behavior.

## Objectives
The goal of this dashboard is to:
- Provide a global view of the Airbnb market in NYC
- Identify the most expensive neighborhoods and property types
- Analyze demand using reviews and reviews per month
- Understand host behavior (single vs multi-listing hosts)
- Estimate potential revenue of listings

## Key Insights
- Most listings are concentrated in Manhattan and Brooklyn
- Entire homes are significantly more expensive than private or shared rooms
- The majority of hosts own only one listing
- A small group of hosts manage multiple properties, indicating professional investors
- Most listings receive fewer than 2 reviews per month

## Dashboard Pages
1. **Overview**
   - KPIs (Total Listings, Avg Price, Reviews)
   - Map of listings
   - Listings by borough

2. **Price Analysis**
   - Average price by borough and room type
   - Price distribution
   - Price vs demand analysis

3. **Reviews Analysis**
   - Top listings by reviews
   - Reviews trend over time
   - Reviews distribution

4. **Host Analysis**
   - Top hosts
   - Listings per host
   - Single vs multi hosts
